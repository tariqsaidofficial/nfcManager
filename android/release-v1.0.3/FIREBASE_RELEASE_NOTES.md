# NFC Manager v1.0.3 - Firebase Release Notes

## 🚨 Critical Security Update

**Alert System Enhanced**: NFC alerts now trigger after just **2 minutes** (previously 15 minutes) with alerts every 2 minutes for better protection against NFC skimming attacks.

## 🌍 Complete Language Support

- **French**: Now 100% translated (was 47% incomplete)
- **Chinese**: Now 100% translated (was almost empty)
- **All 9 languages**: Arabic, German, Spanish, French, Hindi, Russian, Chinese (both), Filipino

## 🎨 UI Improvements

- **Home Screen**: Added today's NFC activity list
- **Onboarding**: Fixed dot alignment
- **Arabic Text**: Fixed text breaking issues
- **Performance**: Improved app responsiveness
